# STATUS.md — free-diy-repair-guides-directory

Last updated: 2026-11-05

## What was built

An offline, single-file static directory of official, free DIY-repair help
(`index.html`, regenerated by `node build.js`):

- 18 resource cards across 5 filterable categories:
  - **Appliance** (6): GE owner support, Whirlpool owner center, Samsung downloads,
    Sears PartsDirect diagrams, AppliancePartsPros diagrams/videos, RepairClinic
    symptom library.
  - **Tech** (3): iFixit guides, Apple Self Service Repair manuals, Framework repair guides.
  - **Auto** (3): ChiltonLibrary (free via library card), AutoZone DIY guides, NHTSA recalls.
  - **Home** (3): Singer/PFAFF/Husqvarna free machine manuals, University of Kentucky
    Extension clothing-repair PDF, UNH Extension "Sewing for Beginners" PDF.
  - **Safety & Recalls** (3): CPSC recalls, Recalls.gov portal, "When repair gets scary"
    pro-territory boundaries card (NFPA primary source; ESFI + gas-utility notes).
- Every card states: what it covers, official source (https link), proof it is free,
  beginner verdict, and per-card `source_checked_date` / `recheck_date`.
- Features: category filter chips with counts, free-text search, escape-safe rendering,
  policy section (no affiliate links, costs, offline behavior), print-friendly CSS.
- **No affiliate links** — verified by tests; all URLs https, no tracking parameters.
- JSON-driven: `data/repair-directory.json` is the source of truth, validated by
  `schema/repair-directory.schema.json` and embedded into the page by `build.js`.
- Tests (no dependencies, Node built-in runner): `tests/schema.test.js` and
  `tests/render.test.js`, including a negative-schema test and build-sync check.
- `LICENSE` (MIT, exact line "Copyright (c) 2026 Asdale Dynamics, LLC") and README
  crediting Asdale Dynamics, LLC.

## How to run it

- Open `index.html` directly in a browser (works offline via `file://`), or
  `python3 -m http.server` in this folder.
- Rebuild after data edits: `node build.js` (or `node build.js --check` to verify sync).
- Run tests: `node --test tests/`
- Verify all source URLs: see repo history; live-URL check performed on 2026-11-05.
